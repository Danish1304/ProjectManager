# Project Manager App

A full-stack MERN application to manage tasks with a modern UI.

## Features
* **Floating Action Button (FAB):** For adding new projects.
* **Modal Form:** To input title and description.
* **Dynamic Routing:** Individual project detail pages.
* **Real-time Updates:** Toggle status and delete projects.

## How to Run
1. **Backend:** Navigate to `/BackEnd`, run `npm install`, then `node index.js`.
2. **Frontend:** Navigate to `/FrontEnd`, run `npm install`, then `npm run dev`.
3. **Database:** Requires MongoDB running on `localhost:27017`.
